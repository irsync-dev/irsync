Resilient file sync over any network topology

Peer-to-peer file and directory sync in the spirit of rsync that adapts to any network topology and survives connection drops without restarting.

Move files and full directory trees directly between devices without configuring firewalls, port forwarding, or static IPs. Built on iroh, transfers punch through NATs, fall back to relays when needed, and handle network switches mid-stream. If a connection drops, the transfer picks up at the exact byte where it stopped.

  1. 1Install

    $ curl --proto '=https' --tlsv1.2 -LsSf https://irsync.org/install.sh | sh -s -- --alpha

    Linux and macOS. Installs irsync and fileset into ~/.local/bin. There is no stable release yet, so --alpha takes the newest alpha release. Other ways to install →

  2. 2First Sync

    $ irsync -av ~/Photos/ myserver:/srv/photos/

    If ssh myserver logs you in, the first run sets the server up too. Later runs connect over iroh and do not use ssh. No ssh? Set the server up by hand → If interrupted, the next run of the same command resumes where the last one stopped.

How it connects

Peer to peer, over iroh

The two machines find each other and traverse NATs and firewalls. The daemon is reached by its iroh identity, not by an address.

Encrypted, key to key

Traffic is encrypted end to end. The client only connects to the daemon key it was given, and the daemon only lets in keys it has granted. Identity and trust →

A relay when there is no direct path

By default a public relay run by n0, the developers of iroh. It cannot read the data. Run your own, or refuse relays with --no-relay. Direct or relay →

Before you rely on it

alpha
  • The command line and the protocol may change before the beta. Keep another copy of anything you sync with it.
  • It is not a drop-in replacement for rsync. It has its own protocol, so both ends must run irsync.
  • Some rsync options are missing, such as -X, -A and -z. Extended attributes and ACLs are not copied.
  • Windows is not supported. Relayed connections are much slower than direct ones.
