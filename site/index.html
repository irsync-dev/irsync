Resilient file sync over any network

Copy files and directory trees the way rsync does, directly between your devices, with irsync on both ends.

  • No open ports. Connects directly through NATs and firewalls, or through a relay when it can't, all powered by iroh.
  • Survives network changes and outages. A transfer keeps going through roaming, brownouts and dropped connections.
  • Private and authenticated. Traffic is encrypted end to end, and each side trusts only the keys it was given.
  • Correctness first. A completed irsync -a --delete of a source that is not changing leaves an exact copy.

Get started

  1. 1

    Install

    $ curl --proto '=https' --tlsv1.2 -LsSf https://irsync.org/install.sh | sh -s -- --beta

    Linux and macOS. Installs irsync and fileset, which checks that a copy is exact, into ~/.local/bin. Other ways to install.

  2. 2

    Sync

    $ irsync -av ~/Photos/ myserver:/srv/photos/

    If ssh myserver logs you in, the first run sets the server up too; later runs connect over iroh, not ssh. No ssh? Set the server up by hand. Interrupted? Run the same command again; it resumes. In scripts, irsync sync -av … is the same command with its name spelled out.

Beta. The command line and the protocol may still change: keep a backup. Windows, extended attributes and ACLs are not supported yet. Known limitations.
