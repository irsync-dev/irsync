Sync files between any two machines, over any network

Copy files and directory trees the way rsync does, directly between your devices, with no port forwarding or static IPs.

  • No open ports, powered by iroh. The two machines find each other through NATs and firewalls, and use a relay only when there is no direct path. More in Direct or relay.
  • Survives network changes. A transfer keeps going when a machine switches networks.
  • Encrypted end to end. Each side talks only to the keys it was given. More in Identity and trust.

Get started

  1. 1

    Install

    $ curl --proto '=https' --tlsv1.2 -LsSf https://irsync.org/install.sh | sh -s -- --beta

    Linux and macOS. Installs irsync and fileset into ~/.local/bin. Other ways to install.

  2. 2

    Sync

    $ irsync -av ~/Photos/ myserver:/srv/photos/

    If ssh myserver logs you in, the first run sets the server up too; later runs connect over iroh, not ssh. No ssh? Set the server up by hand. Interrupted? Run the same command again; it resumes.

Beta. Both ends run irsync, and it may still change: keep a backup. Known limitations.

Before you rely on it

  • The command line and the protocol may change before the first stable release. Keep another copy of anything you sync with it.
  • It is not a drop-in replacement for rsync. It has its own protocol, so both ends must run irsync.
  • Some rsync options are missing, such as -X, -A and -z. Extended attributes and ACLs are not copied.
  • Windows and NTFS is not supported. Relayed connections are much slower than direct ones.

The full list is in Known limitations.

Help

Ask questions and report bugs in GitHub Issues. If a first sync fails, see Troubleshooting. Report security problems privately to security@irsync.org.

Also included: fileset

A helper that checks that a copy is exact, whichever tool made it: rsync, rclone, cp or irsync. Start with the introduction to fileset.
