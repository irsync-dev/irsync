Remote sync through firewalls and over bad networks

irsync takes the rsync flags you already know. It needs no port forwarding or dynamic DNS, and after a drop, a closed laptop or Ctrl-C, the same command carries on where it stopped.

Introduction → · Tutorial → · Contributing →

  1. 1Install

    $ curl --proto '=https' --tlsv1.2 -LsSf https://irsync.org/install.sh | sh -s -- --alpha

    Linux and macOS. Installs irsync and fileset into ~/.local/bin. Other ways to install →

  2. 2Sync

    $ irsync -av ~/Photos/ myserver:/srv/photos/

    If ssh myserver logs you in, this sets the server up too. No ssh? Set the server up by hand →
