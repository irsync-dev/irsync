# NAME

irsync.toml - configuration file for irsync

# SYNOPSIS

```text
~/.config/irsync/irsync.toml
```

<!-- chapters -->

# FILES

| File | Holds |
| --- | --- |
| `~/.config/irsync/irsync.toml` | The configuration; `$XDG_CONFIG_HOME/irsync/irsync.toml` when that is set. `--config PATH` names another file. |

The key files, the lock file and the state directory are described under
FILES in irsync(1).
