# pbwalk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A command-line tool, `pbwalk`, that turns an `IRSYNC_CAPTURE` file into an exact per-message, per-field byte account with totals.

**Architecture:** The capture file format (pcapng with Wireshark's exported-PDU header) moves out of `irsync` into a new library crate `pbcap`, which also defines a minimal "envelope" that any wrapper record can follow. A second new crate, `pbwalk` (library and binary), reads packets through `pbcap`, walks the protobuf bytes itself using message definitions loaded at run time, unwraps the envelope, and prints the listing and totals. `pbwalk` contains no irsync code; irsync's protos are only its built-in default.

**Tech Stack:** Rust (workspace edition 2021, rust 1.96), `prost`, `prost-reflect`, `protox`, `prost-build`, `clap`, `anyhow`, `thiserror`. All are already workspace dependencies.

**Spec:** `docs/superpowers/specs/2026-11-22-pbwalk-design.md`. Read it before starting any task.

## Global Constraints

- No new third-party dependencies. Use `{ workspace = true }` for everything.
- Both new crates start with `#![forbid(unsafe_code)]` and have `[lints] workspace = true`, `version.workspace`, `rust-version.workspace`, `edition.workspace`, `license.workspace`, as `crates/filegen/Cargo.toml` does.
- The bytes irsync writes to a capture file do not change. `crates/irsync/tests/capture.rs` and the unit tests in `crates/irsync/src/net/tap/capture.rs` keep passing with no change to what they assert.
- `proto/irsync/capture/v1/record.proto` is not edited.
- `pbwalk` and `pbcap` never panic and never allocate from an unchecked length on bad input. A reader or walker problem is an error value or a labelled row.
- `pbwalk` source has no reference to irsync types or field names other than: the dependency on `irsync_proto::FILE_DESCRIPTOR_SET`, and the default value of `--type`, `irsync.capture.v1.Record`.
- Envelope numbering, verbatim from the spec: fields 1 to 19 are the wrapper's own (2 `direction`, 10 `encoded_len`, 11 `trimmed`); 20 to 39 the message; 40 and up events.
- Row labels, verbatim: `cut content`, `cut, not itemised`, `message not captured`, `not in the capture, unexplained`.
- Commit messages: a short summary line, a blank line, a brief plain-English reason. No attribution trailers of any kind.
- Work stays on branch `pbwalk`. Do not push or open the PR; the last task says what to hand back.
- Everyday test run: `cargo test -q --workspace --all-features --no-fail-fast`. Before the last commit: `tools/ci.sh check`.

## Review Focus

Inputs the spec implies but its listed tests do not exercise. Each has a test in the task named.

1. A capture cut off mid-packet (irsync was killed while writing): everything read so far is listed and totalled, then one error line says the file is truncated, exit status 1. (Task 5)
2. `--type` names a type the protos do not have, or `--proto-path` points at a directory with no `.proto` files or one with a syntax error: one error line naming the type or the file, exit status 2, nothing listed. (Task 4)
3. A pcapng that is not an exported-PDU capture, such as one from `tcpdump` (link type 1): an error that says so and gives the link type, not a wall of undecodable packets. (Task 1)
4. A capture with no packets, or with only events: listing is empty or events only, totals print zeros, no division by zero in the share column. (Task 5)
5. Output piped into `head`: `pbwalk` stops quietly with status 0 when its output closes, no panic message. (Task 5)

```rust
/// Wireshark refuses a packet larger than this.
pub const MAX_PACKET: usize = 262_144;
pub const LINKTYPE_WIRESHARK_UPPER_PDU: u16 = 252;

pub mod write {
    pub fn section_header() -> Vec<u8>;
    pub fn interface(linktype: u16, snaplen: u32) -> Vec<u8>;
    pub fn packet(ts_micros: u64, payload: &[u8]) -> Vec<u8>;
    /// `protocol` is the text for Wireshark's protocol column.
    pub fn exported_pdu(protocol: &str, src: Ipv6Addr, dst: Ipv6Addr,
                        src_port: u32, dst_port: u32, body: &[u8]) -> Vec<u8>;
}

pub struct Packet {
    pub ts_micros: u64,
    /// The exported-PDU tags before the end tag, as (tag, value with padding).
    pub tags: Vec<(u16, Vec<u8>)>,
    pub body: Vec<u8>,
}
impl Packet {
    pub fn src(&self) -> Option<Ipv6Addr>;      // tag 22
    pub fn dst(&self) -> Option<Ipv6Addr>;      // tag 23
    pub fn src_port(&self) -> Option<u32>;      // tag 25
    pub fn dst_port(&self) -> Option<u32>;      // tag 26
}

#[derive(Debug, thiserror::Error)]
pub enum Error {
    #[error(transparent)] Io(#[from] std::io::Error),
    #[error("the capture is cut off in the middle of a block")] Truncated,
    #[error("not an exported-PDU capture: link type {0}, want 252")] LinkType(u16),
    #[error("not a capture file this tool reads: {0}")] Malformed(&'static str),
}

/// Reads one packet at a time. `new` reads up to and including the first
/// Interface Description Block and checks the link type.
pub struct Reader<R: std::io::Read> { /* private */ }
impl<R: std::io::Read> Reader<R> {
    pub fn new(input: R) -> Result<Self, Error>;
}
impl<R: std::io::Read> Iterator for Reader<R> {
    type Item = Result<Packet, Error>;   // after an Err, the next call is None
}
```

- Reader rules: little-endian sections only (byte-order magic `0x1a2b3c4d`, else `Malformed`); a block's total length must be a multiple of 4, at least 12, at most 16 MiB (`16 << 20`), and equal its trailing copy, else `Malformed`; block types other than section header (`0x0a0d0d0a`), interface (1) and enhanced packet (6) are skipped; a second interface block with another link type is `LinkType`; end of input exactly between blocks ends the iteration, anywhere else is `Truncated`; a zero-byte input is `Truncated`. Timestamps are microseconds, as the writer writes them.

### Task 3: The walker

**Files:**
- Create: `crates/pbwalk/Cargo.toml` (lib and `[[bin]] name = "pbwalk"`; dependencies `pbcap`, `irsync-proto`, `prost`, `prost-reflect`, `protox`, `clap`, `anyhow`; dev `tempfile`), `crates/pbwalk/src/lib.rs`, `crates/pbwalk/src/walk.rs`, a `src/main.rs` that only prints "not yet" for now

**Interfaces:**
- Produces:

```rust
#[derive(Clone, Copy, Default, PartialEq, Eq, Debug)]
pub struct Sizes { pub tag: u64, pub len: u64, pub value: u64 }
impl Sizes { pub fn total(&self) -> u64 }

pub struct Field<'a> {
    pub number: u32,              // 0 for Undecodable
    pub name: Option<String>,     // None when the type has no such field
    pub sizes: Sizes,
    pub value: Value<'a>,
}
pub enum Value<'a> {
    /// A number, bool or enum, already printed: "5", "true", "SIDE_DAEMON(2)".
    Scalar(String),
    Bytes(&'a [u8]),              // bytes and string fields
    Message { type_name: String, fields: Vec<Field<'a>> },
    /// A packed repeated field: every element, printed.
    Packed(Vec<String>),
    /// A field number the type does not have; the raw value bytes.
    Unknown { wire_type: u8, raw: &'a [u8] },
    /// Bytes from here to the end of the enclosing message do not parse.
    Undecodable(&'a [u8]),
}

pub const MAX_DEPTH: usize = 64;

/// Every field of `bytes`, in the order it appears. Never panics.
pub fn walk<'a>(desc: &prost_reflect::MessageDescriptor, bytes: &'a [u8]) -> Vec<Field<'a>>;
```

- Size rules: `tag` is the size of the field key varint; `len` is the size of the length varint for wire type 2, else 0; `value` is the rest. For `Message`, `value` equals the sum of its children's totals. For `Undecodable`, `tag` and `len` are 0 and `value` is the number of bytes left.
- A length-delimited field is a `Message` when the type says so, `Packed` when the type says a repeated scalar, `Bytes` for `bytes` and `string`, and `Unknown` when the number is not in the type. A known field whose wire type contradicts its declared type is `Unknown`. A nested message deeper than `MAX_DEPTH` is `Bytes`. Wire types 3 and 4 (groups), a bad varint, a length that runs past the message, and field number 0 end the enclosing message with `Undecodable`. A packed field whose elements do not parse cleanly is `Unknown`.

pub struct Schema { /* a prost_reflect::DescriptorPool */ }
impl Schema {
    /// irsync's protos, from irsync_proto::FILE_DESCRIPTOR_SET.
    pub fn builtin() -> Schema;
    /// Every .proto file under each directory, each directory an include root.
    pub fn from_dirs(dirs: &[std::path::PathBuf]) -> anyhow::Result<Schema>;
    pub fn message(&self, full_name: &str) -> anyhow::Result<prost_reflect::MessageDescriptor>;
}

#[derive(Clone, Copy, PartialEq, Eq, Debug, clap::ValueEnum)]
pub enum Prefix { Varint, None }

#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Kind { Message, Event, Raw }

pub struct Entry<'a> {
    pub kind: Kind,
    /// Short name of the payload's type ("Hello"); the wrapper's for Raw;
    /// "" when there is no payload.
    pub type_name: String,
    /// The wrapper's own fields as (name, printed value), in file order,
    /// without encoded_len and trimmed. Empty for Raw.
    pub header: Vec<(String, String)>,
    pub direction: pbcap::v1::Direction,     // Unspecified for Raw
    pub fields: Vec<Field<'a>>,              // the payload's; the packet's for Raw
    pub present: u64,                        // payload bytes in the file
    pub wire_len: u64,                       // encoded_len; present for Raw; 0 for Event
    pub prefix: u64,
    pub cut_content: u64,
    pub cut_pieces: u64,
    pub cut_other: u64,
    pub dropped_entries: u64,
    pub not_captured: u64,
    pub unexplained: u64,
    /// Why the numbers do not add up, if they do not.
    pub mismatch: Option<String>,
}
impl Entry<'_> {
    /// present + cut_content + cut_other + not_captured + unexplained == wire_len
    pub fn adds_up(&self) -> bool;
    /// The printed value of wrapper field `name`; its default's printed
    /// form when the record does not carry it.
    pub fn header_value(&self, wrapper: &prost_reflect::MessageDescriptor, name: &str) -> Option<String>;
}

/// One packet, unwrapped by the envelope rules.
pub fn unwrap<'a>(wrapper: &prost_reflect::MessageDescriptor, body: &'a [u8], prefix: Prefix) -> Entry<'a>;
/// One packet as it is in the file.
pub fn raw<'a>(desc: &prost_reflect::MessageDescriptor, body: &'a [u8]) -> Entry<'a>;
```

- `unwrap` rules, with `gap = encoded_len - present`:
  - The payload is the wrapper's top-level `Message` field numbered 20 or up. In `MESSAGE_FIELDS`: `Kind::Message`. From `FIRST_EVENT_FIELD` up: `Kind::Event`, all byte counts 0, `prefix` 0.
  - No such field and `encoded_len > 0`: `Kind::Message`, `type_name` `""`, `not_captured = encoded_len`.
  - No such field and `encoded_len == 0`: `Kind::Event` with no fields.
  - `trimmed` set: `cut_content = sum(content.len)`, `cut_pieces = content.len()`, `cut_other = gap - cut_content`, `dropped_entries` from it.
  - `trimmed` not set and `gap > 0`: `unexplained = gap`.
  - `mismatch` is set, and the cut numbers are left 0, when: `encoded_len < present`; the cut content is larger than `gap`; more than one field is numbered 20 or up (the first is used); the body does not decode as an `Envelope`; or the wrapper's walk ends in `Undecodable`.
  - `prefix` is `prost::encoding::encoded_len_varint(encoded_len)` for `Prefix::Varint` and `Kind::Message`, else 0.

#[derive(clap::Parser, Debug, Clone)]
#[command(name = "pbwalk", about = "List every field of a protobuf capture with its size")]
pub struct Args {
    pub file: std::path::PathBuf,
    #[arg(long = "proto-path", value_name = "DIR")] pub proto_path: Vec<std::path::PathBuf>,
    #[arg(long = "type", value_name = "NAME", default_value = "irsync.capture.v1.Record")] pub type_name: String,
    #[arg(long)] pub no_unwrap: bool,
    #[arg(long, value_enum, default_value = "varint")] pub prefix: Prefix,
    #[arg(long = "where", value_name = "F=V")] pub filters: Vec<String>,
    #[arg(long, value_name = "F,...", value_delimiter = ',')] pub group_by: Vec<String>,
    #[arg(long, conflicts_with = "no_totals")] pub totals_only: bool,
    #[arg(long)] pub no_totals: bool,
    #[arg(long)] pub full: bool,
}

#[derive(Default, Debug, PartialEq, Eq)]
pub struct Summary {
    pub packets: u64,        // read from the file
    pub messages: u64,       // Kind::Message or Raw that passed --where
    pub wire_bytes: u64,     // sum of wire_len over those
    pub prefix_bytes: u64,
    pub mismatches: u64,
    pub truncated: bool,
}

/// Reads the capture from `input`, writes the listing and totals to `out`.
/// Err for anything that stops the run before a packet is read (bad
/// arguments, bad protos, not a capture). A closed `out` ends the run
/// quietly with Ok.
pub fn run(args: &Args, input: impl std::io::Read, out: &mut impl std::io::Write) -> anyhow::Result<Summary>;
```

- `lib.rs` also has `pub use clap::Parser;`, so the capture test and the fuzz target can call `Args::parse_from` (with `use pbwalk::Parser as _;`) without depending on clap themselves.
- Exit status in `main.rs`: 0 when `mismatches == 0 && !truncated`; 1 otherwise, after printing to stderr `pbwalk: N message(s) do not add up` and/or `pbwalk: the capture is cut off; totals cover what was read`; 2 with `pbwalk: <error>` for an `Err`. `args.file` is opened in `main.rs`, buffered.
- `--where F=V`: `F` must be a field of the wrapper type, else `Err`. A record passes when `Entry::header_value(F)` equals `V`, or equals `V` followed by `(`…`)` (so `side=SIDE_CLIENT` and `side=SIDE_CLIENT(1)` both match). With `--no-unwrap`, `--where` and `--group-by` are an `Err`.
- Listing, one block per entry that passes, numbered by packet from 1:

```text
#6 0.012345 fd69:7273::2 → fd69:7273::1:0:0 port 1  Hello  38 B + 1 B prefix
   side=SIDE_DAEMON(2) direction=DIRECTION_RECEIVED(2) stream=STREAM_KIND_CONTROL(1) connection=2
  protocol_version = 5                  2 B  (tag 1, value 1)
  path = "m"                            3 B  (tag 1, len 1, value 1)
  preserve: Hello.Preserve             18 B  (tag 2, len 1, value 15)
    links = true                        2 B  (tag 1, value 1)
  cut content                     262,144 B  (1 piece)
  cut, not itemised                     4 B  (7 entries dropped)
  DOES NOT ADD UP: <mismatch text>
```

  Time is seconds since the first packet, six decimals. Children indent two spaces per level. An event's first line ends `StreamEvent  event` with no sizes. `message not captured` and `not in the capture, unexplained` are rows like the cut rows. Unknown fields print as `#99 (varint)`; undecodable bytes as `N bytes not decodable`. Byte counts use `,` as the thousands separator. Exact column widths are free.
- Values: `Bytes` prints quoted when it is valid UTF-8 with no control characters, else as hex. Without `--full`, a byte string longer than 32 bytes prints its first 32 and `… (N bytes)`, and a `Packed` longer than 8 elements prints its first 8 and `… (N values)`.
- Totals, after the listing, each table sorted by bytes, largest first, with a share column that prints `-` when the grand total is 0:
  - **By message**: type, count, bytes (`wire_len`), share.
  - **By field**: path, bytes, share. A leaf's path gets its whole size; a `Message` field's path gets its `tag + len` only. Paths are `Hello.preserve.links`: the payload's short type name, then field names; unknown fields `Hello.#99`; undecodable bytes `Hello (not decodable)`. The four cut labels appear as `DataChunk (cut content)` and so on; with no payload, `(message not captured)`.
  - **Overhead**: length prefixes, tags, length bytes, values, and one line for all bytes not in the capture.
  - **By direction**: sent, received, unspecified, and the sum; bytes include prefixes.
  - **By `<field>`**, one table per `--group-by` field, keyed by `header_value`.
