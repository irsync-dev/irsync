# filegen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A standalone `filegen` binary that applies a seeded, resumable, Markov-driven sequence of POSIX filesystem operations to a directory tree and leaves a YAML state dump and a timed operation log outside the tree.

**Architecture:** An in-memory arena model of the tree (sorted children, per-subtree kind counts) is the only source for target choices, so every decision is a pure function of the PRNG state and the sorted tree. A transition matrix picks the next operation kind from the previous one, with a size-cap pressure term; a locality-biased weighted descent picks targets; one module per operation kind applies it (or records it in dry-run mode) and returns what the log needs. The run loop times each step, checkpoints the state file, and handles signals.

**Tech Stack:** Rust 2021 (workspace member), clap 4 derive, serde + serde_yaml_ng, rand 0.8 + rand_chacha 0.3 (ChaCha8Rng, `serde1`), nix 0.31 (signals, utimensat, mkfifo, mknod, fallocate), libc 0.2 (macOS `F_PUNCHHOLE`), xattr, unicode-normalization, jiff, indicatif, anyhow/thiserror, tempfile for tests.

**Spec:** `docs/superpowers/specs/2026-10-20-filegen-design.md`

## Global Constraints

- Crate lives at `crates/filegen/`, binary `filegen`, library `filegen`; it must not depend on `irsync`, `irsync-proto` or `fileset`. New dependencies are added to the root `Cargo.toml` `[workspace.dependencies]` and referenced with `workspace = true`.
- `rand = "0.8"`, `rand_chacha = { version = "0.3", features = ["serde1"] }` (matches the workspace's `rand_core 0.6`), `serde_yaml_ng = "0.10"`, `unicode-normalization = "0.1"`, `libc = "0.2"`.
- Paths inside the model and the log are byte strings (`Vec<u8>` / `OsStr`), relative to the root, components joined by `/`, root is the empty path. Generated names are UTF-8 in NFC form; pre-existing names may be anything.
- Every stat is `lstat`. Symlinks are never followed. Every path filegen writes is `root.join(rel)` where every ancestor of `rel` is a `Dir` node in the model, so no symlink can ever be an ancestor of a written path.
- Entries named `.fileset*` (any depth), entries with `st_dev != root st_dev`, sockets and unknown kinds are `OffLimits` nodes: present in the model for name collisions and subtree flags, never targets, never descended into.
- Directory listings are sorted bytewise before use. No decision reads a `HashMap` iteration order or the clock.
- Caps: `max_file_size` default 256 MiB, `max_total_size` default 25 GiB, by apparent size; hard links count once per link; never exceeded, not even transiently.
- `max_depth` default 32, `max_path_len` default 900 bytes (relative path); start-up check: canonical root length + 1 + `max_path_len` ≤ PATH_MAX (1024 macOS, 4096 Linux), else exit 2.
- Output directory lookup: `--out-dir`, then config `out_dir`, then `$FILEGENTMP`, then `$TMPDIR`, then `/tmp`. Files: `<prefix>.log`, `<prefix>.state.yaml`; dry run: `<prefix>.dry.log`, `<prefix>.dry.state.yaml`; default prefix `filegen-<seed>`. Refuse (exit 2) if the output directory lies inside the root, or if `--seed` finds either file present and `--force` is not given.
- Exit codes: 0 ok, 1 failed operation or I/O error, 2 usage/config error, 130 SIGINT, 143 SIGTERM.
- State file written atomically (temp file in the same directory, rename) at the end, on abort, on interrupt, and every `checkpoint_steps` (default 1000) steps. `format_version` is 1.
- Config: YAML, every key optional, unknown keys are an error (exit 2) naming the key. Precedence: built-in defaults < config file (and the `config` block of a resumed state file, applied first) < `--set` < flags.
- Timing covers filesystem syscalls of the step only (plus `fsync` when `fsync: true`), reported in microseconds.
- Platforms: Linux and macOS; CI runs `cargo fmt --all --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test --workspace` on both. Tests that need hole punching, root, or non-UTF-8 names skip or `#[cfg]` themselves.

## Review Focus

1. **Root given as a symlink or with a trailing slash**: expected to canonicalize and work on the target directory, with the output-directory containment check done against the canonical root. Pinned in Task 13 (`run_root_symlink_and_trailing_slash`).
2. **Pre-existing entries filegen does not understand** (a socket, a non-UTF-8 name, a `.fileset.sqlite` at depth 3): expected to be modelled as off limits, logged escaped, never touched, never a panic. Pinned in Task 4 (`walk_marks_off_limits`, `walk_non_utf8_name`) and Task 14 (`cli_never_touches_planted_manifests`).
3. **A filesystem error mid-run** (the root disappears, ENOSPC): expected exit 1 with a failure line in the log, a footer, and a state file that resumes. Pinned in Task 13 (`run_failure_writes_state_and_footer`).
4. **A typo in a config key or `--set` path**: expected exit 2 naming the key, never a silent default. Pinned in Task 3 (`config_unknown_key_is_error`, `config_set_unknown_key_is_error`) and Task 14 (`cli_bad_config_exits_2`).
5. **Resume after the tree was altered by hand**: expected to continue deterministically from the altered tree, never panic on a missing anchor, and record the new entry count. Pinned in Task 13 (`run_resume_after_external_change`).

### Task 4: Tree model and the start-up walk

**Files:**
- Create: `src/model.rs`, `src/walk.rs`
- Test: unit tests in both

**Interfaces:**
- Produces in `model.rs`:
  - `pub type NodeId = u32;`
  - `pub enum NodeKind { Dir, File, Symlink, Fifo, Device, OffLimits }` with `fn index(self) -> usize` (0..6) and `const COUNT: usize = 6`.
