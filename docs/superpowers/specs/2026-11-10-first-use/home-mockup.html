irsync — resilient file synchronization

A one-way directory synchroniser in the mould of rsync, rebuilt for today's networks. Same flags, same trailing-slash rule.

It connects through iroh, so it gets through NATs and firewalls without port forwarding or dynamic DNS. A transfer outlives the network connection: after a drop, a closed laptop or Ctrl-C, the same command picks up where it stopped.

  • Linux or macOS on both ends
  • Rust, to build it
  • ssh access to the server (optional)

Install irsync Your first sync

Install

irsync builds from source with Rust's cargo. No Rust yet? Get it from rustup.rs first. The build takes a few minutes.

$ curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh   # only if you have no Rust
$ cargo install --git https://github.com/irsync-dev/irsync irsync

Release binaries will be provided once the beta starts; until then, cargo is the way in.

Linux and macOS, x86_64 and aarch64. With ssh, the client is enough: the first sync copies irsync to the server when both run the same OS and CPU.
